# Detective rank artwork

Asset: `frontend/public/art/detective-ranks.png`. Generated using the built-in image generation tool, with transparency preserved. The image is a five-column, three-row atlas; rendering selects a cell without modifying the source image.

Columns: Unlisted (0–200), Clue Hunter (201–400), Field Investigator (401–600), Senior Detective (601–800), Professional Detective (801–1,000).

Rows: female, male, neutral (Others and guests). Saved accounts use their best completed virtual case score within each difficulty for the rank and their selected gender for the character. The result card separately displays the current case score and best score for that difficulty.

Generation prompt:

Create a polished game character sprite atlas for ROOMVERSE detective rank cards. One single transparent PNG atlas in an exact uniform grid of FIVE columns and THREE rows (15 equally sized cells). Each cell contains ONE centered waist-up adult detective, fully isolated with generous transparent padding. No text, numbers, borders, backgrounds or shadows outside figures. Consistent cinematic illustrated game art, elegant teal and gold lighting, friendly intelligent faces, sharp readable silhouettes. Row 1: female detectives. Row 2: male detectives. Row 3: androgynous gender-neutral detectives. Within EVERY row left to right show five progressively higher ranks: column1 unlisted beginner in simple charcoal jacket holding notebook; column2 clue hunter in brown jacket with magnifying glass; column3 field investigator in teal trench coat with evidence folder; column4 senior detective in navy tailored trench coat and silver badge; column5 professional detective in elegant black and gold trench coat with gold detective badge and confident folded arms. Equal cell sizes, exact 5x3 grid, all figures same waist-up scale with head and hands inside their cell. Intended for programmatic cropping at exact fifths of image width and thirds of image height. Transparent background.

Scanner cards show a personal practice score and never a leaderboard rank.

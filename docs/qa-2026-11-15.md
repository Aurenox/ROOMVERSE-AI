## Changes made during this review
- Added an explicitly selected isolated Django test configuration and separate Next.js build directory. Test accounts, scores and archived questions were kept out of the real application database.
- Updated older browser tests for the dedicated leaderboard page, variable hint content and globally exhausted changed-image variants.
- Made speech assertions deterministic with simulated installed voices.
- Excluded generated test-build files from ESLint. An initial lint pass scanned those generated files; the corrected configuration passed.
- No application defect was reproduced in the completed suite after updating those stale test assumptions.

## Limits
- Mobile testing uses browser emulation, not a physical phone. Camera tests use synthetic feeds, not an actual webcam or phone camera.
- Speech selection and text dispatch were tested; human-perceived audio quality and every operating system voice were not.
- Download was verified. Native share sheets, external email delivery, production HTTPS/hosting and large-scale load were not verified.
- Two live Gemini calls used fictional evidence and generic object names only, with no user photographs or account data. Both passed. Future quota exhaustion, provider outages, hallucinations and semantic paraphrases remain possible; validation and fallback reduce risk but cannot prove all generated prose correct or unique.
- Original saved rounds intentionally retain their original content.

## Repeatable local browser setup
Use config.e2e_settings for Django on port 8120, run migrations into backend/e2e.sqlite3, and build/start Next.js with ROOMVERSE_E2E=1 and DJANGO_ORIGIN=http://127.0.0.1:8120 on port 3120. Run the suite with ROOMVERSE_TEST_URL=http://127.0.0.1:3120 and `npx playwright test --workers=2`. This configuration disables Gemini and uses its own SQLite database. Test databases, screenshots and build artifacts are ignored by git.

# Three-minute demo

| Time | Show |
| --- | --- |
| 0:00–0:25 | Open the case archive. Show the virtual worlds and the distinction between watching a timed scene and investigating a room photograph. |
| 0:25–0:55 | Open Room Scanner. Upload a photo of ordinary objects without sensitive details and grant consent. Point out the detection source and edit a result. |
| 0:55–1:25 | Select Spy Mission or Reality Glitch and generate the case. Show the exhibit order and the “fictional evidence ledger” label. |
| 1:25–2:10 | Solve several questions by ordering stations, computing an interval, and locating the hand-off. |
| 2:10–2:35 | Ask Nova for a hint. Show the shared hint counter and explain the 25-point deduction. |
| 2:35–2:50 | Explain the manual workflow. If live requests fail, use the airplane-safe workflow: upload the same photo, manually enter its objects, and show the Prepared mystery label. |
| 2:50–3:00 | Submit the final answer, show the score and evidence review, then share the numerical result. |

Before recording, run a real photo with the hackathon API project and verify two requests fit its current quota. Open a validated prepared case separately as a backup. The included Midnight Office case is another demonstration option and needs no API access. Confirm the event rules and submission dates for the specific hackathon.
